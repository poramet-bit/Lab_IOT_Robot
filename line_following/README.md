# หุ่นยนต์ตามเส้น 5 จุด

เปิด `line_following.ino` ใน Arduino IDE เลือก **Arduino UNO R4 WiFi** และติดตั้งไลบรารี **ArduinoBLE** เก็บ `line_controller.h` ในโฟลเดอร์เดียวกัน

## สายและตำแหน่ง

เซนเซอร์ AO เรียงจาก **ซ้ายจริงไปขวาจริง**: `A5, A4, A3, A2, A1` วัดด้านจากท้ายรถมองไปข้างหน้า วางหน้าเซนเซอร์ห่างพื้นประมาณ 2.5 มม. ใช้กราวด์ร่วมกับบอร์ด

- มอเตอร์ซ้ายจริง: PWM 10, IN 8/9 (ช่อง R ในโค้ดเดิม)
- มอเตอร์ขวาจริง: PWM 5, IN 7/6 (ช่อง L ในโค้ดเดิม)
- ไฟล์นี้ไม่ใช้ LED, encoder หรือ gyro; A4/A5 ใช้กับเซนเซอร์เส้น จึงต้องถอดสาย gyro ออกจากสองขานี้

## วิธีใช้

เชื่อม Bluetooth **IOT-LINE** ผ่านแอป BLE UART และเปิด TX Notify

- `f` หรือ `START`: เริ่มตามเส้น
- `s` หรือ `STOP`: เบรกทันทีและรอเริ่มใหม่
- `v`: อ่านค่าเซนเซอร์หนึ่งครั้งขณะหยุด แสดง RAW และ BLACK จากซ้ายไปขวา

BLE ใช้ Nordic UART: service `6E400001-B5A3-F393-E0A9-E50E24DCCA9E`, TX ลงท้าย `0003`, RX ลงท้าย `0002` ในกลุ่ม UUID เดียวกัน Serial Monitor ใช้ 115200 baud

ก่อนวิ่ง ส่ง `v` โดยวางเซนเซอร์บนเส้นดำและพื้นไม้ตามลำดับ ค่า ADC อยู่ในช่วง 0–1023 ค่าเริ่มต้น `THRESHOLD=512` และ `BLACK_IS_HIGH=true` **ยังไม่ได้วัดกับสนามจริง** หากดำอ่านต่ำกว่าพื้นให้เปลี่ยน `BLACK_IS_HIGH=false` แล้วตั้ง threshold ของแต่ละตัวระหว่างค่าที่อ่านบนดำกับพื้น เช่น ดำ 800 พื้น 300 ใช้ประมาณ 550; `BLACK=1` ต้องตรงกับตัวที่อยู่บนเส้นดำ ไม่มีคำสั่งคาลิเบรตอัตโนมัติ

## พฤติกรรม

ใช้ตัวกลางเป็นหลักเมื่อยังเห็นเส้นต่อ และไม่นำจุดดำฝั่งนอกที่แยกจากกลุ่มตรงกลางมาดึงรถออก เมื่อมีเส้นกว้างต่อเนื่องทั้งแผงจะรักษาการเดินตรง จึงเป็นหลักการเลือกตรงจากรูปแบบเซนเซอร์ ไม่ใช่การรู้ล่วงหน้าว่าเส้นใดเป็นทางหลอก

เมื่อเจอเส้นเฉพาะริมซ้าย/ขวา หรือหลุดเส้น จะหมุนค้นหาฝั่งที่เห็นล่าสุด โดยเบรกล้อด้านในและขับล้อด้านนอกไปหน้า ต้องเห็นเส้นตรงกลางต่อเนื่อง 3 รอบอ่านจึงกลับมาตามเส้น ค้นหาได้ไม่เกิน 2 วินาที จากนั้นเบรกและรอ `f` ถ้าไม่เคยเห็นฝั่งใดมาก่อนจะเบรกทันที สุดเส้นใช้กติกาค้นหาเดียวกัน ไม่มีเครื่องหมายเส้นชัยเฉพาะ

Bluetooth หลุดจะเบรก และเชื่อมใหม่แล้วต้องส่ง `f` ใหม่ มอเตอร์ไม่เริ่มเองตอนเปิดบอร์ด

## จูน

ใน `line_controller.h`:

- `basePwm=35000`: ความเร็วเดินตรงเริ่มต้น
- `searchPwm=35000`: ความเร็วค้นหา/เลี้ยว 90 องศา
- `gainPwm=7000`: แรงปรับทิศตามตำแหน่งเส้น
- `maxPwm=50000`: เพดาน PWM
- `searchTimeoutMs=2000`: เวลาค้นหาสูงสุด

ชื่อซ้าย/ขวาในไฟล์ใหม่นี้เป็นด้านจริง ตั้งต่างจากชื่อช่อง L/R เก่า การเลี้ยวด้วยล้อประคองล็อกมุมต้องทดสอบจริง; ระยะหน้าแผงและการลื่นของล้อมีผลต่อโค้ง 90 องศา

## ทดสอบบนคอมพิวเตอร์

จากรากโปรเจกต์:

```sh
g++ -std=c++11 -Wall -Wextra -pedantic tests/line_controller_test.cpp -o /tmp/line_controller_test
/tmp/line_controller_test
```

การทดสอบนี้ตรวจ logic ควบคุม ไม่แทนการคอมไพล์ด้วย Arduino core หรือการทดสอบบนรถจริง
