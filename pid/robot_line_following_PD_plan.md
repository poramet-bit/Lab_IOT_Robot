# สรุปแผนงานรถหุ่นยนต์ Line Following ด้วย PD Controller

## 1. เป้าหมายของโปรเจกต์

พัฒนารถหุ่นยนต์ 2 ล้อให้สามารถวิ่งตามเส้นได้อัตโนมัติ โดยใช้

-   Arduino UNO WiFi R4 เป็นตัวควบคุม
-   TCRT5000 แบบ 5 ช่อง (5CH) สำหรับตรวจจับเส้น
-   L298N สำหรับควบคุมมอเตอร์ DC ซ้ายและขวา
-   มอเตอร์ DC 2 ตัว
-   LM393 สำหรับตรวจจับรอบล้อ/ความเร็วล้อ (ถ้าใช้งานในระบบ)
-   HC-SR04 สำหรับตรวจจับสิ่งกีดขวาง (ถ้าใช้งานในระบบ)

แนวทางควบคุมการวิ่งตามเส้นจะใช้ **PD Controller** ซึ่งเป็นส่วน P + D ของ PID

------------------------------------------------------------------------

## 2. หลักการทำงาน

ลำดับการทำงาน:

``` text
TCRT5000 5CH
     ↓
อ่านค่าจากเซนเซอร์ทั้ง 5 ตัว
     ↓
คำนวณ Position ของเส้น
     ↓
คำนวณ Error
Error = Position - Setpoint
     ↓
คำนวณ PD
Output = (Error × Kp) + ((Error - LastError) × Kd)
     ↓
ปรับความเร็วมอเตอร์ซ้าย/ขวา
     ↓
L298N
     ↓
มอเตอร์ซ้าย + มอเตอร์ขวา
```

------------------------------------------------------------------------

## 3. การกำหนดตำแหน่งของ TCRT5000 5CH

กำหนดค่าตำแหน่งของเซนเซอร์ 5 ตัวให้เรียงจากซ้ายไปขวา เช่น

``` text
S1      S2      S3      S4      S5
1500    2500    3500    4500    5500
                ↑
             ตำแหน่งกลาง
```

กำหนด Setpoint:

``` text
Setpoint = 3500
```

ตัวอย่าง:

### เส้นอยู่ตรงกลาง

``` text
Position = 3500
Error = 3500 - 3500
      = 0
```

รถจะวิ่งตรง

### เส้นอยู่ทางขวา

``` text
Position = 4500
Error = 4500 - 3500
      = +1000
```

PD จะสร้าง Output เพื่อปรับความเร็วมอเตอร์ให้รถหันกลับเข้าหาเส้น

### เส้นอยู่ทางซ้าย

``` text
Position = 2500
Error = 2500 - 3500
      = -1000
```

PD จะปรับมอเตอร์ในทิศทางตรงข้าม

> หมายเหตุ: ค่าตำแหน่งและเครื่องหมายของ Error
> ต้องตรวจสอบกับทิศทางการติดตั้งเซนเซอร์จริง หากรถเลี้ยวผิดทิศสามารถกลับเครื่องหมายของ
> Error หรือสลับการบวก/ลบ Output ได้

------------------------------------------------------------------------

## 4. PD Controller

### P - Proportional

ใช้แก้ความคลาดเคลื่อนจากเส้นในปัจจุบัน

``` text
P = Error × Kp
```

ถ้า Error มาก → การแก้ไขมาก\
ถ้า Error น้อย → การแก้ไขน้อย

### D - Derivative

ใช้ดูว่า Error เปลี่ยนเร็วแค่ไหน

``` text
D = (Error - LastError) × Kd
```

ช่วยลดอาการรถส่ายและช่วยให้รถตอบสนองต่อการเปลี่ยนทิศของเส้นได้ดีขึ้น

### รวม P + D

``` text
Output = P + D
```

หรือ

``` text
Output = (Error × Kp)
       + ((Error - LastError) × Kd)
```

------------------------------------------------------------------------

## 5. การปรับมอเตอร์

กำหนดความเร็วพื้นฐาน:

``` text
BaseSpeed
```

แล้วใช้ Output ปรับมอเตอร์:

``` text
LeftMotor  = BaseSpeed + Output
RightMotor = BaseSpeed - Output
```

จากนั้นจำกัดค่าความเร็วไม่ให้เกินช่วง PWM ที่กำหนด เช่น

``` cpp
leftMotor  = constrain(leftMotor, -255, 255);
rightMotor = constrain(rightMotor, -255, 255);
```

> ถ้าระบบมอเตอร์ใช้ช่วง PWM 0--100 หรือช่วงอื่น ต้องปรับ `constrain()`
> ให้ตรงกับโค้ดจริง

------------------------------------------------------------------------

## 6. ขา L298N ของรถ

จากการกำหนดขาปัจจุบัน:

### มอเตอร์ซ้าย

``` cpp
ENA = 10;
IN1 = 9;
IN2 = 8;
```

### มอเตอร์ขวา

``` cpp
ENB = 5;
IN3 = 7;
IN4 = 6;
```

ต้องตรวจสอบทิศทางจริงของมอเตอร์อีกครั้ง
เพราะการต่อสายมอเตอร์หรือการวางตัวรถอาจทำให้ซ้าย/ขวากลับด้าน

------------------------------------------------------------------------

## 7. ฟังก์ชันที่ต้องสร้าง

### 7.1 อ่านค่า TCRT5000

สร้างฟังก์ชันสำหรับอ่านค่าเซนเซอร์ทั้ง 5 ช่อง

``` cpp
readSensors();
```

ต้องกำหนดก่อนว่าเซนเซอร์ให้ค่าอะไรเมื่อเจอเส้นดำ/พื้นขาว เช่น

``` text
เจอเส้นดำ → LOW
ไม่เจอเส้น → HIGH
```

หรือกลับกัน ขึ้นอยู่กับบอร์ดและการตั้งค่า

### 7.2 Position()

สร้างฟังก์ชันคำนวณตำแหน่งของเส้น

``` cpp
Position();
```

ผลลัพธ์ที่ต้องการคือค่าประมาณ:

``` text
1500 – 5500
```

โดยค่ากลางคือ

``` text
3500
```

### 7.3 PD()

สร้างฟังก์ชันคำนวณ PD

``` cpp
PD(BaseSpeed, Kp, Kd);
```

ภายในทำ:

``` cpp
error = Position() - 3500;

output = (error * Kp)
       + ((error - last_error) * Kd);

last_error = error;
```

### 7.4 motors()

ส่งค่าที่คำนวณแล้วไปควบคุมมอเตอร์

``` cpp
motors(leftMotor, rightMotor);
```

## 8. การทดสอบเป็นขั้นตอน

### ขั้นที่ 1: ทดสอบ TCRT5000

ยังไม่ต้องเปิดมอเตอร์

ตรวจสอบว่าเซนเซอร์ทั้ง 5 ตัวอ่านค่าได้ถูกต้อง

``` text
S1
S2
S3
S4
S5
```

### ขั้นที่ 2: ทดสอบ Position()

นำรถไปวางบนเส้นแล้วดูค่า Position ผ่าน Serial Monitor

ตัวอย่าง:

``` text
เส้นซ้าย  → Position ต่ำ
เส้นกลาง → Position ≈ 3500
เส้นขวา  → Position สูง
```

### ขั้นที่ 3: ทดสอบมอเตอร์

ตรวจสอบว่า

``` text
LeftMotor  → ล้อซ้าย
RightMotor → ล้อขวา
```

และตรวจสอบทิศทางการหมุน

### ขั้นที่ 4: เริ่มใช้ P

เริ่มจาก

``` text
Kd = 0
```

แล้วปรับ Kp

เป้าหมายคือให้รถสามารถตามเส้นได้ แต่ยังไม่ส่ายมากเกินไป

### ขั้นที่ 5: เพิ่ม D

เพิ่ม Kd เพื่อช่วยลดการส่าย

สังเกต:

-   รถส่ายซ้ายขวา → ปรับ Kd
-   รถตอบสนองช้า → ปรับ Kp
-   รถเลี้ยวแรงเกินไป → ลด Kp หรือปรับ BaseSpeed
-   รถหลุดเส้นตอนเข้าโค้ง → ปรับ Kp / BaseSpeed / Kd

### ขั้นที่ 6: ปรับ BaseSpeed

เมื่อ PD ทำงานได้แล้ว จึงเพิ่ม BaseSpeed เพื่อให้รถวิ่งเร็วขึ้นโดยยังไม่หลุดเส้น

------------------------------------------------------------------------

## 9. ค่าเริ่มต้นสำหรับทดลอง

สามารถเริ่มทดลองจากค่าขนาดเล็ก เช่น

``` cpp
BaseSpeed = 80;
Kp = 0.05;
Kd = 0.10;
```

จากนั้นปรับตามพฤติกรรมจริงของรถ

> ค่า Kp และ Kd ไม่มีค่าที่ถูกต้องตายตัว ต้องปรับตามชนิดมอเตอร์ น้ำหนักรถ ความเร็ว
> เซนเซอร์ และสนามที่ใช้

------------------------------------------------------------------------

## 10. สิ่งที่ยังต้องตรวจสอบกับวงจรจริง

ก่อนเขียนโค้ดฉบับสมบูรณ์ ต้องยืนยัน:

1.  TCRT5000 5CH ต่อเข้าขา Arduino ใดบ้าง
2.  ลำดับ S1--S5 จากซ้ายไปขวา
3.  ค่าเซนเซอร์เมื่อเจอเส้นดำเป็น HIGH หรือ LOW
4.  ช่วง PWM ที่ใช้จริง
5.  ทิศทางการหมุนของมอเตอร์ซ้าย/ขวา
6.  LM393 ใช้สำหรับวัดรอบล้อหรือยังไม่ใช้
7.  HC-SR04 ต้องการให้หยุด/หลบสิ่งกีดขวางหรือยังไม่ใช้

------------------------------------------------------------------------

## 11. เป้าหมายสุดท้าย

เมื่อเสร็จแล้ว รถควรสามารถ:

-   ตรวจจับเส้นด้วย TCRT5000 5CH
-   คำนวณตำแหน่งเส้น
-   คำนวณ Error จากจุดกึ่งกลาง
-   ใช้ PD Controller คำนวณการแก้ทิศทาง
-   ปรับความเร็วมอเตอร์ซ้าย/ขวาแบบอัตโนมัติ
-   วิ่งตามเส้นตรงได้
-   เข้าโค้งได้
-   ลดอาการส่ายด้วยค่า Kd
-   สามารถปรับ BaseSpeed, Kp และ Kd เพื่อจูนรถให้เหมาะกับสนามจริง
