# บังคับมือ (Manual Control)

อัปโหลด `manual_control.ino` — ใช้ pin/ค่าจูนเดียวกับ `robotcurclerun.ino`/`dice_movement.ino` (ฮาร์ดแวร์ตัวเดียวกัน)

เชื่อม BLE ชื่อ **MANUAL-ROBOT** (Nordic UART, UUID ลงท้าย 0001/0002/0003 เหมือนสเก็ตช์อื่น) หรือ USB Serial Monitor 115200 baud ก็ได้ ไม่ต้องมี newline ก็ทำงาน

| คำสั่ง | ทำงาน |
|---|---|
| `w` | เดินหน้า `STEP_CM` แล้วเบรกหยุดเอง |
| `b` | ถอยหลัง `STEP_CM` แล้วเบรกหยุดเอง |
| `a` | หมุนซ้ายอยู่ที่เดิม `STEP_DEG` องศา |
| `d` | หมุนขวาอยู่ที่เดิม `STEP_DEG` องศา |
| `v` | รายงานสถานะ (ความเร็ว, ระยะ/มุมต่อสเต็ป, BLE, encoder) |
| `stop` | เบรกฉุกเฉินทันที ล็อกคำสั่งอื่นจนกว่าจะ `start` |
| `start` | ปลดล็อกฉุกเฉิน |
| `cm <n>` | ตั้งระยะต่อสเต็ปของ `w`/`b` เป็น n ซม. |
| `deg <n>` | ตั้งมุมต่อสเต็ปของ `a`/`d` เป็น n องศา |
| `spd <n>` | ตั้งความเร็ววิ่งตรง (20000-65535) |

ทุกคำสั่งเดินหน้า/ถอย/หมุน จบเองแล้วเบรกอัตโนมัติ ไม่มี auto-repeat/timeout ให้จำ ส่งคำสั่งใหม่ได้ทันทีหลังคำสั่งก่อนจบ

BLE หลุดกลางคันจะเบรกและล็อกเหมือน `stop` ทันที ต้องส่ง `start` ปลดล็อกเมื่อเชื่อมกลับ
