# Simple Avoid — เหตุการณ์เดียวคงที่

อัปโหลด `simple_avoid.ino` มอเตอร์/encoder ใช้ค่าจูนเดียวกับ `robotcurclerun.ino`/`manual_control.ino` เซนเซอร์หน้าใช้ขาเดียวกับ `obstacle_avoidance` (HC-SR04: ECHO=A0, TRIG=A1)

ลำดับตายตัว (ไม่มีการเลือกเส้นทาง, เลี้ยวซ้ายครั้งเดียวตอนกลับแนวหลังเลี่ยงเท่านั้น ไม่มีเลี้ยวซ้ายตั้งต้น):

1. วิ่งตรงไปเรื่อยๆ จนเจอสิ่งกีดขวางหน้า (ระยะ `FRONT_STOP_CM`, ค่าเริ่ม 20 ซม.) แล้วเบรกหยุด
2. เลี้ยวขวา `TURN_DEG` เพื่อเลี่ยง
3. วิ่งตรง `DETOUR_CM` (ค่าเริ่ม 40 ซม.) ผ่านสิ่งกีดขวาง
4. เลี้ยวซ้าย `TURN_DEG` กลับแนวเดิม
5. วิ่งตรง `RESUME_CM` (ค่าเริ่ม 60 ซม.) แล้วจบภารกิจ

เชื่อม BLE ชื่อ **SIMPLE-AVOID** (Nordic UART UUID เดียวกับสเก็ตช์อื่น) หรือ USB Serial 115200 baud

| คำสั่ง | ทำงาน |
|---|---|
| `start` / `f` | เริ่มเหตุการณ์ตั้งแต่ต้น |
| `stop` / `s` | เบรกฉุกเฉิน ยกเลิกเหตุการณ์ที่ทำอยู่ |
| `v` | รายงานสถานะ/ค่าที่ตั้งไว้ |
| `deg <n>` | ตั้งมุมเลี้ยว (ใช้ทั้งจุดเลี้ยวซ้ายแรกและเลี่ยง/กลับ) |
| `stopcm <n>` | ตั้งระยะหน้าที่ถือว่าเจอสิ่งกีดขวาง |
| `detour <n>` | ตั้งระยะวิ่งผ่านสิ่งกีดขวางหลังเลี้ยวขวา |
| `resume <n>` | ตั้งระยะวิ่งต่อหลังเลี้ยวซ้ายกลับแนวเดิม |
| `spd <n>` | ตั้งความเร็ววิ่งตรง (20000-65535) |

ข้อจำกัด: ไม่มี servo สแกนหรือ IR รอบตัว ทิศเลี้ยวคงที่ทุกครั้ง ไม่ปรับตามระยะจริงที่วัดได้ (ต่างจาก `obstacle_avoidance`) ไม่มี echo จากเซนเซอร์หน้าต่อเนื่องเกิน 1.5 วินาทีระหว่างวิ่ง = ถือว่าเซนเซอร์เสีย หยุดแจ้งเหตุ ไม่ถือว่าทางโล่ง

ยังไม่ได้ compile-check ด้วย arduino-cli (ไม่มีไบนารีในเครื่องตอนนี้) และยังไม่ได้ทดสอบรถจริง
