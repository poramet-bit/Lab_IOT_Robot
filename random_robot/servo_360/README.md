## 🔌 การต่อสาย (Pin Connection)
| ขา Servo | สาย | บอร์ด Arduino / Robot |
|---|---|---|
| **Signal (สัญญาณ)** | สีส้ม / ขาว | **A2** (หรือเปลี่ยนในโค้ดตัวแปร `SERVO_PIN`) |
| **VCC (ไฟเลี้ยง)** | สีแดง | **5V** (หรือแหล่งจ่ายไฟภายนอกสำหรับ Servo) |
| **GND (กราวด์)** | สีน้ำตาล / ดำ | **GND** |

---

## ⚙️ การทำงานของโปรแกรม
1. **การตั้งค่าเริ่มต้น (Setup):**
   - เมื่อจ่ายไฟหรือกดปุ่ม Reset โปรแกรมจะสั่งงาน Servo ไปที่ตำแหน่ง **90** ทันที และหน่วงเวลา 2 วินาทีเพื่อให้เข้าตำแหน่ง
2. **การทำงานวนลูปอัตโนมัติ (Loop):**
   - หมุนไปที่ **0** (ค้างไว้ 3 วินาที)
   - หมุนกลับมาที่ **90** (ค้างไว้ 3 วินาที)
   - หมุนไปที่ **180** (ค้างไว้ 3 วินาที)
   - หมุนกลับมาที่ **90** (ค้างไว้ 3 วินาที)
3. **การสั่งการผ่าน Serial Monitor:**
   - Baud Rate: `115200`
   - สามารถพิมพ์ส่งค่า `0`, `90`, หรือ `180` เข้ามาเพื่อบังคับมุมได้ทันที

---

## 💡 หมายเหตุเรื่องชนิดของเซอร์โว 360
- **กรณีเป็น 360 Continuous Rotation Servo (หมุนต่อเนื่อง 360 องศา):**
  - ค่า `90` คือ **หยุดหมุน (Neutral / STOP)** *(หากยังมีอาการหมุนเบาๆ ให้ใช้ไขควงปรับ potentiometer ใต้ตัว Servo เพื่อ Calibrate จุดหยุด)*
  - ค่า `0` คือ หมุนทิศทางที่ 1 เต็มความเร็ว
  - ค่า `180` คือ หมุนทิศตรงกันข้ามเต็มความเร็ว
- **กรณีเป็น Positional Servo (ควบคุมตำแหน่งองศา):**
  - ค่า `0` = 0 องศา
  - ค่า `90` = 90 องศา (กึ่งกลาง)
  - ค่า `180` = 180 องศา
