# หลบสิ่งกีดขวางที่ 25 ซม. — เลือกทางที่ ultrasonic วัดได้ไกลที่สุด

เปิด `obstacle_avoidance_no_servo.ino` ใน Arduino IDE เลือก **Arduino UNO R4 WiFi** ติดตั้งไลบรารี **Servo** แล้วอัปโหลด ไม่มี scenario, Bluetooth หรือ encoder

คงชื่อโฟลเดอร์/ไฟล์เดิมไว้ แต่รุ่นนี้ **ใช้ servo ที่ A2 แล้ว** ค่ามอเตอร์ การจับคู่ซ้าย/ขวา มุม servo และเวลาเลี้ยวอ้างอิงจาก [Max_Speed/obstacle_avoidance_auto](../../Max_Speed/obstacle_avoidance_auto/obstacle_avoidance_auto.ino) โดยใช้ค่าตัวแปรจริงในโค้ดต้นทาง: servo **150° หันซ้าย / 90° หันหน้า / 30° หันขวา**

เปิดเครื่อง/รีเซ็ต → รอ **3 วินาที** → เดินอัตโนมัติ ไม่ต้องต่อ USB หรือส่งคำสั่งเริ่ม

## การต่อขาและทิศทาง

| อุปกรณ์ | ขา |
|---|---|
| มอเตอร์ช่อง A PWM / A / B | D5 / D6 / D7 |
| มอเตอร์ช่อง B PWM / A / B | D10 / D9 / D8 |
| HC-SR04 ECHO / TRIG | A0 / A1 |
| Servo สายสัญญาณ | A2 |
| IR หน้าซ้าย / หน้าขวา OUT | A4 / A3 |
| ว่าง | A5 / D2 / D3 / D11 |

ใช้ `MOTOR_SIDES_SWAPPED=true`, `LEFT_INVERTED=false`, `RIGHT_INVERTED=false` และ `IR_SIDES_SWAPPED=true` ตามต้นทาง คำสั่งหมุนขวาจึงส่งช่อง A ถอย / ช่อง B เดินหน้า ส่วนหมุนซ้ายส่งช่อง A เดินหน้า / ช่อง B ถอย โดย trim ยังอยู่ที่ช่อง B

IR ตรวจพบเมื่อ LOW ใช้กราวด์ร่วมกับวงจรขับมอเตอร์และแหล่งจ่าย servo โดย A2 ใช้ส่งสัญญาณเท่านั้น ไม่ใช่ขาจ่ายไฟให้ servo

## การทำงาน

1. เดินหน้าขณะ ultrasonic ไกลกว่า **25 ซม.** และ IR ซ้าย/ขวาไม่พบวัตถุ
2. ถ้า ultrasonic วัดได้ **ไม่เกิน 25 ซม.** หรือ IR ตัวใดตัวหนึ่งพบวัตถุ จะเบรก **250 ms** แล้วถอย **180 ms**
3. เมื่อถอยครบจึงหยุดรถและใช้ servo สแกน **ขวา → ซ้าย → กลับตรงหน้า** รอ servo นิ่ง 300 ms ทุกครั้ง ด้านข้างเก็บระยะด้านละ 3 ครั้งก่อนตัดสินใจ ถอยเพียง **หนึ่งครั้งก่อนสแกนแต่ละรอบ** ไม่ถอยระหว่างเปลี่ยนมุมภายในรอบเดียวกัน
4. เมื่อมีค่าระยะด้านหน้าใหม่ จะเปรียบเทียบ **ซ้าย / หน้า / ขวา** แล้วเลือกทางที่วัดได้ไกลที่สุด ด้านข้างต้องมีระยะอย่างน้อย **25 ซม.** และ IR ฝั่งนั้นไม่พบวัตถุ ด้านหน้าต้องไกลกว่า **25 ซม.** และ IR ทั้งคู่ไม่พบวัตถุ ใช้ระยะที่วัดได้เต็มช่วง **2–400 ซม.** เพื่อจัดอันดับ ไม่ตัดค่าระยะที่ 25 ซม. และไม่มีส่วนต่าง 15 ซม. เพื่อให้สิทธิ์ขวาอีกแล้ว
5. ถ้าด้านหน้าไกลที่สุดหรือเสมอด้านที่ไกลที่สุด จะเดินตรงต่อ ถ้าเลือกด้านข้างและซ้าย/ขวาเท่ากันพอดีจะเลือกขวา ถ้าไม่มีทางผ่านเกณฑ์ หรือด้านหน้ายังใกล้ไม่เกิน **8 ซม.** จะ **เบรก → ถอย 180 ms → หยุดสแกนรอบใหม่** เมื่อมีทางจึงไปต่อเอง
6. ถ้าเลือกด้านข้าง จะหมุนประมาณ 90° ตามเวลา **450 ms** แล้วเบรก อ่านระยะทิศใหม่ และเดินต่อ IR ฝั่งที่กำลังเลี้ยวหรือระยะหน้าไม่เกิน 8 ซม. จะหยุดการหมุน แล้วถอยหนึ่งครั้งก่อนสแกนเลือกทางใหม่เช่นกัน

ตัวอย่าง: ซ้าย 70 / หน้า 18 / ขวา 60 ซม. → เลือกซ้าย; ซ้าย 200 / หน้า 300 / ขวา 250 ซม. → เดินหน้า; ซ้าย 390 / หน้า 18 / ขวา 375 ซม. → เลือกซ้าย หาก IR พบวัตถุที่ฝั่งใด ฝั่งนั้นจะถูกตัดออกจากตัวเลือก

นับเวลาการเคลื่อนที่ด้วย `millis()` เพื่ออ่านเซนเซอร์ระหว่างหมุนได้ ขณะขับรถ servo จะหันหน้าตลอด และจะไม่ใช้ค่าระยะด้านข้างแทนระยะด้านหน้า ชุดทดสอบซอฟต์แวร์ยืนยันสัญญาณมอเตอร์ได้ แต่ทิศทางและมุมหมุนจริงยังต้องตรวจบนรถ

เบรกใช้ A=B=HIGH และ PWM **255 ทั้งสองช่อง** ตามค่าต้นทาง ไม่ใช้ trim กับค่าเบรก โปรเจกต์นี้ยังถอยแบบจับเวลา **180 ms** เนื่องจากไม่มีการอ่าน encoder เพื่อควบคุมระยะถอย 10 ซม. แบบต้นทาง

รุ่นนี้ไม่มีเซนเซอร์หลัง การถอยแต่ละครั้งจำกัดด้วยเวลา 180 ms แต่ถ้ายังหาทางไม่ได้จะถอยเพิ่มก่อนสแกนแต่ละรอบ จึงต้องเว้นพื้นที่ด้านหลังและเฝ้าดูขณะทดสอบ รถตรวจสิ่งกีดขวางด้านหลังไม่ได้ มุมเลี้ยวเป็นค่าประมาณจากเวลา ต้องตรวจบนรถจริง

## ค่าจูน

แก้ที่ `Settings.h`:

| ค่า | ค่าปัจจุบัน |
|---|---|
| RUN_PWM / TURN_PWM / REVERSE_PWM | 180 / 160 / 130 ก่อน trim |
| BRAKE_PWM | 255 ทั้งสองช่อง |
| RIGHT_TRIM | 46800/55500 — เดินตรงได้ช่อง A 180 / ช่อง B 151 |
| MOTOR_SIDES_SWAPPED / IR_SIDES_SWAPPED | true / true ตาม Max_Speed |
| LEFT_INVERTED / RIGHT_INVERTED | false / false |
| TURN_LEFT_90_MS / TURN_RIGHT_90_MS | 450 / 450 ms |
| START_DELAY_MS | 3000 ms |
| BRAKE_MS / BACKUP_MS | 250 / 180 ms |
| FRONT_STOP_CM / TURN_STOP_CM | 25 / 8 ซม. |
| SIDE_CLEAR_CM | 25 ซม. |
| SERVO_LEFT / SERVO_FRONT / SERVO_RIGHT | 150° / 90° / 30° |
| SERVO_SETTLE_MS / SONAR_SAMPLES | 300 ms / 3 ครั้งต่อด้าน |
| PING_INTERVAL_MS / ECHO_TIMEOUT_US | 60 ms / 30000 µs |
| IR_ACTIVE_LOW | true |

ไม่มีการเลือกเลข scenario, คำสั่ง USB หรือ fault ที่ต้องปลดล็อก หากข้อมูล ultrasonic ผิดปกติขณะเดินหน้าจะหยุดรอ หากอยู่ในรอบหลบและยังเลือกทางไม่ได้จะถอยและสแกนใหม่ เมื่ออ่านได้จะทำต่อเอง รีเซ็ตบอร์ดเพื่อเริ่มนับ 3 วินาทีใหม่ การตั้ง servo หันหน้าตอนเปิดเครื่องไม่ทำให้ถอย และยังรอครบ 3 วินาทีก่อนเริ่มขับ

คงนโยบาย no-echo เดิม: ไม่มี echo ติดต่อกัน 3 ครั้งในทิศเดียวกันจะยังอนุญาตให้เลือกทิศนั้นได้ โดย IR ยังตรวจวัตถุอยู่ แต่การจัดอันดับทั้งสามทิศ **ให้ทางที่วัดระยะโล่งได้จริงมาก่อนทาง no-echo** ไม่ถือว่า no-echo เป็นระยะไกลที่สุด สถานะนี้แยกพื้นที่ไม่มีผิวสะท้อนออกจากเซนเซอร์/สายที่ไม่ส่ง echo ไม่ได้ สำหรับด้านข้างที่มี echo ต้องได้ค่าถูกต้องอย่างน้อย 2 ใน 3 ครั้ง และใช้ค่าที่ใกล้ที่สุดของด้านนั้นเป็นระยะเปรียบเทียบ เพื่อไม่ให้ echo ที่ไกลผิดปกติเพียงครั้งเดียวชนะ

## ตรวจซอฟต์แวร์

จากโฟลเดอร์ `random_robot`:

```sh
simple_test_dir=$(mktemp -d /tmp/simple-avoid-tests.XXXXXX)
g++ -std=c++11 -Wall -Wextra -Werror -pedantic -Iobstacle_avoidance_no_servo/tests/stubs -Iobstacle_avoidance/tests/stubs obstacle_avoidance_no_servo/tests/sketch_tests.cpp -o "$simple_test_dir/sketch_tests"
"$simple_test_dir/sketch_tests"
arduino-cli compile --fqbn arduino:renesas_uno:unor4wifi obstacle_avoidance_no_servo
```

ทดสอบจำลอง 15 กรณี: ค่ามอเตอร์และการจับคู่ซ้าย/ขวาตาม Max_Speed, ระยะหยุด 25 ซม., เลือกทางที่ไกลที่สุดรวมด้านหน้า, ระยะต่างกันเล็กน้อยและระยะไกลถึง 390 ซม., IR ยับยั้งทางที่พบวัตถุ, no-echo, เวลาเลี้ยว 450 ms, รอเริ่ม 3 วินาที, หยุดรถและรอ servo นิ่งก่อนสแกน, ถอยหนึ่งครั้งก่อนสแกนทุกรอบ, การกู้คืนเมื่อติดมุม/หมุนถูกขวาง/echo ผิดปกติ และเวลาล้น ยังไม่ได้อัปโหลดหรือทดลองรถจริง
