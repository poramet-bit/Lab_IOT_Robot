# หุ่นยนต์หลบสิ่งกีดขวางอัตโนมัติ (ไม่มี Bluetooth)

สเก็ตช์แยกจาก `obstacle_avoidance` เดิม (BLE+scenario) — เปิด `obstacle_avoidance_auto.ino` ใน Arduino IDE ติดตั้งไลบรารี **Servo** แล้วอัปโหลด ปล่อยรถวางบนพื้นแล้ววิ่งหาทางเองทันที ไม่ต้องส่งคำสั่งใดๆ

บอร์ด: **Arduino UNO R4 WiFi** (`arduino:renesas_uno:unor4wifi`)

## ขา

| อุปกรณ์ | ขา |
|---|---|
| มอเตอร์ซ้าย PWM / A / B | D5 / D6 / D7 |
| มอเตอร์ขวา PWM / A / B | D10 / D9 / D8 |
| HC-SR04 TRIG / ECHO | A1 / A0 |
| Servo หมุน ultrasonic | A2 |
| IR หน้าซ้าย / หน้าขวา | A3 / A4 |
| IR หลังซ้าย / หลังขวา | A5 / D2 |
| Encoder ล้อซ้าย (มอเตอร์ D5) / ล้อขวา (มอเตอร์ D10) | D11 / D3 |

เดินหน้า A=LOW,B=HIGH; ถอย A=HIGH,B=LOW; เบรก A=B=HIGH, PWM=255 ชดเชยล้อขวาด้วย `RIGHT_TRIM` ตาม `robotline_fullspeed` IR ตั้งต้นว่าเจอวัตถุเมื่อ LOW (`IR_ACTIVE_LOW`) — เช็คจริงแล้วกลับค่าถ้าโมดูลเป็นตรงข้าม

## การทำงาน

แบ่งระยะเป็น 2 ชั้น:

1. ขับตรงไปเรื่อยๆ ที่ `RUN_PWM`
2. **วัตถุอยู่ไกล** (ultrasonic หน้า < `FRONT_DEVIATE_CM` แต่ยัง >= `FRONT_STOP_CM`) → ไม่หยุด แค่หมุน servo แว้บดูซ้าย/ขวาเร็วๆ (`SERVO_GLANCE_MS`) แล้วเบี่ยงพวงมาลัยหลบไปทางที่โล่งกว่าโดยลดพีดับเบิ้ลยูเอ็มล้อฝั่งที่จะเลี้ยวเข้า (`DEVIATE_TRIM`) ยังวิ่งต่อเนื่อง
3. **วัตถุใกล้** (IR หน้าซ้าย/ขวา เจอวัตถุ หรือ ultrasonic หน้า < `FRONT_STOP_CM`) → หยุดทันที ถอยสั้นๆ (`BACKUP_MS`, ยกเลิกถอยทันทีถ้า IR หลังเจอวัตถุ) แล้วหมุน servo สแกนซ้าย/ขวา เลี้ยวไปทางที่โล่งกว่า (ใช้เวลา `TURN_90_MS` โดยประมาณ ไม่ใช่มุมวัดจริง)
4. ถ้าทั้งสองข้างตันหมด (< `SIDE_MIN_CM`) หลังถอยแล้ว — หมุนต่อรอบเดียว (`TURN_90_MS`) แล้วให้ลูปถัดไปสแกนใหม่
5. วนซ้ำตลอดไป ไม่มีจุดจบ ไม่มีพิกัด ไม่มีเส้นทางเฉพาะสนาม

## ต้องจูนกับรถจริง

- `TURN_90_MS`, `BACKUP_MS` — เวลาไม่ผูกกับมุม/ระยะจริง ต้องวัดจากรถจริงแล้วปรับ
- `RUN_PWM`, `TURN_PWM`, `REVERSE_PWM` — ปรับตามกำลังมอเตอร์จริง
- `DEVIATE_TRIM` — ยิ่งมากยิ่งหักโค้งแรงตอนเบี่ยงหลบระยะไกล ถ้าเบี่ยงไม่พอให้เพิ่ม
- `FRONT_DEVIATE_CM`, `FRONT_STOP_CM`, `SIDE_MIN_CM` — ระยะเริ่มเบี่ยง / ระยะหยุดถอย / ระยะเลือกทาง (ต้อง `FRONT_DEVIATE_CM > FRONT_STOP_CM`)
- `IR_ACTIVE_LOW` — กลับค่าถ้า IR ให้ HIGH ตอนเจอวัตถุ

ไม่มีการวัดพัลส์ล้อ ไม่มีพิกัดประมาณ ไม่มี BLE/Serial command — เป็น reactive obstacle avoidance ล้วนๆ ยังไม่ได้ทดสอบบนรถจริง

## บอร์ดค้างและพอตหาย

อาการ: อัปโหลดเสร็จแล้วบอร์ดค้าง `/dev/ttyACM0` หายไปจาก Arduino IDE

UNO R4 WiFi ใช้ USB CDC จากตัวชิปเอง ถ้าสเก็ตช์ค้างหรือถูก interrupt ท่วม พอตจะหายตามไปด้วย ในโค้ดเดิมขา encoder ตั้งเป็น `INPUT` ลอยๆ แล้ว `attachInterrupt(..., CHANGE)` สัญญาณรบกวนจากมอเตอร์จึงยิง interrupt รัวไม่หยุด จนลูปหลักและ USB CDC ไม่ได้ทำงาน ตอนนี้แก้เป็น `INPUT_PULLUP` (ตั้งก่อน `attachInterrupt` เพราะ core ของ R4 เก็บ pull-up ที่มีอยู่แล้วเท่านั้น ไม่เพิ่มให้) และนับขอบเดียวด้วย `RISING` เหมือน `robotcurclerun` กับ `simple_avoid`

นอกจากนี้ขา encoder เดิมสลับข้าง (`ENC_LEFT = 3, ENC_RIGHT = 11`) ทำให้เครื่องหมายของ error ในตัวคุมวิ่งตรงกลับด้าน หุ่นจะยิ่งเบี่ยงออกแทนที่จะกลับเข้าแนว แก้เป็น `ENC_LEFT = 11, ENC_RIGHT = 3` ตามการเดินสายจริง

**กู้พอตกลับมา**: กดปุ่ม RESET สองครั้งเร็วๆ บอร์ดจะเข้าบูตโหลดเดอร์และพอตจะโผล่ขึ้นมาใหม่ แล้วค่อยอัปโหลด

ถ้าพอตยังหายเฉพาะตอนมอเตอร์ออกแรง สาเหตุคือไฟตก ไม่ใช่โค้ด: ต้องจ่ายไฟมอเตอร์แยกจาก USB และต่อกราวด์ร่วมกัน
